# Commercial Licensing — GOE Platform

GOE is open source software, licensed under the GNU Affero General Public License v3 (AGPL v3).

## What AGPL v3 means

You are free to use, study, modify, and distribute GOE under AGPL v3 terms. The key condition: if you run a modified version of GOE as a network service (e.g. a hosted web application), you must make your modified source code available to users of that service under the same AGPL v3 terms.

This prevents "run as a service without sharing changes" — the loophole that standard open source licenses leave open.

## Commercial / closed-source licensing

If you need to deploy GOE in a closed or proprietary environment — without open-sourcing your modifications — a commercial license is available.

Commercial licensing is appropriate for:
- Organisations deploying GOE internally without sharing source
- Products built on GOE that cannot be released under AGPL v3
- White-label or embedded deployments
